# Devanagari Fonts

Place Devanagari Unicode TrueType/OpenType font files here:
- `NotoSansDevanagari-Regular.ttf`
- `NotoSerifDevanagari-Regular.ttf`
- Or any compatible Devanagari font.

Note: On Windows systems, `C:\Windows\Fonts\Nirmala.ttc` provides Devanagari rendering if no local font is placed here.
