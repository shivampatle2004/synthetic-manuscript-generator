# Sharada Fonts

Place Sharada script TrueType/OpenType font files here:
- `NotoSansSharada-Regular.ttf`
- Or any compatible Sharada font.

Download: [Google Noto Sans Sharada](https://fonts.google.com/noto/specimen/Noto+Sans+Sharada)

If missing, the generator will halt with a clear error prompt to place the font here.
